# CHANGELOG

App Store / Google Play に出したリリースノートを、バージョンごとにそのまま残す場所です。

実装・リファクタ・内部の仕様といった開発の詳細は書きません
（それらは commit と `docs/` にあります）。ここに置くのは利用者が読む文章だけです。

- ファイル名はバージョン番号（`1.1.0.md`）
- **初回リリースは 1.1.0**。公開前のテスト配布で 1.0.0 を使ったため、番号を進めてある
- ストアは日本限定配信のため、日本語のみ。配信地域を広げるか、
  App Store Connect に英語のローカライズを足したときに `1.2.0.en.md` の形で並べる
