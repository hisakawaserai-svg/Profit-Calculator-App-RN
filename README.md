# うりつみ (Uritsumi)

フリマアプリの出品者向け、**利益計算＆売上記録アプリ**。iOS / Android 対応。

手数料・送料・梱包材を引いて「手元にいくら残るか」をその場で出し、そのまま記録として残せます。
出品者が実際に困る場面 ——「この値段で出して大丈夫？」「そろそろ値下げしたいけど、どこまで下げられる？」「確定申告の書類、どうしよう」—— を 1 つずつ拾って形にしました。

## 計算タブ — 出品する前に

  <img src="docs/screenshots/03_reverse.png" width="220" alt="目標から逆算" />
</p>

#### 純利益の計算
販売価格・仕入価格・送料・手数料・梱包材・その他を入れると、手元に残る額が画面上部に大きく出ます。入れた欄だけで計算するので、全部埋める必要はありません。スクロールで結果が流れても、固定バーに小さく出し続けます。

#### 内訳の帯グラフ
「内訳」を開くと、引かれる分が色分けの帯で出ます。手数料・送料・梱包材のどれがいちばん重いのかがひと目で分かります。

#### 目標から逆算
「ほしい利益」を入れると、必要な販売価格を逆算します。計算と逆算は対等な 2 択で、同じ 1 本の帯をどちら側から見るかの違いです。

#### その場で使える電卓
金額欄の横の電卓ボタンから、行をいくつでも積める簡易電卓が開きます。「箱代 + テープ代」を別々に入れて合計だけを欄へ入れる、といった使い方ができます。開き直すと前の行がそのまま残っています。

#### 不用品 / 仕入品の切り替え
仕入品を選ぶと仕入価格の欄が増え、見出しも「利益」に変わります。

## 記録タブ — 出品してから、売れるまで

<p align="center">

  <img src="docs/screenshots/06_detail.png" width="220" alt="記録の詳細" />
  <img src="docs/screenshots/04_simulator.png" width="220" alt="値下げシミュレータ" />
</p>

#### 一覧
出品中と売却済みを切り替えて、月ごとに一覧できます。写真のサムネイル・商品名・純利益が並び、上部に月の収支が出ます。検索、期間・種別・タグでの絞り込み（タグは OR 条件）、並べ替えに対応。

#### 記録の中身
写真・商品名・タグ・メモ・販売日・目標利益。既存の記録から**複製**すれば、同じような商品を続けて出すときに入力をやり直さずに済みます。

#### 詳細画面
金額の内訳を帯グラフと引き出し線で表示。長押しで金額をコピーできます。出品からの経過日数も出ます。

#### 値下げシミュレータ
出品中の記録から「いくらで売る？」を開くと、価格スライダーが出ます。動かすと純利益がその場で変わり、**あといくらまで下げられるか**（赤字になる手前）が分かります。目標利益を決めておけば、その線も一緒に引かれます。決めた価格はそのまま記録に反映できます。

## データタブ — 振り返る

<p align="center">
  <img src="docs/screenshots/05_data.png" width="220" alt="データタブ" />
</p>

#### 3 つの見かた

- **収支** — 月ごとの純利益と、その累計をグラフで表示。前の期間との比較も出せます
- **タグ別** — どのジャンルが稼げているかをタグごとに集計
- **実績** — 続けるほど増えていくアチーブメント

期間の切り替え（月・年・全期間）と、種別・タグでの絞り込みに対応。

#### 実績
「はじめての売却」「累計利益 10 万円」「得意分野」など。難易度に応じてブロンズ〜レジェンドの段位が付き、達成するとトーストで知らせます。数字を追うだけでは続かないので、**続けること自体に手応えを持たせる**ために入れた機能です。

## 設定タブ — 手間を減らす・データを守る

#### 使いかた
計算 / 記録 / 売る / データ / 残す / ことば の各ページに分けて、図つきで収録。各画面の右上の「？」からは、その画面の説明だけが開きます。

#### チュートリアル
初回起動時にひと通りの流れを案内します。設定からいつでも見直せます。

#### よく使う値（プリセット）
送料・販売サイト・梱包材をあらかじめ登録しておくと、選ぶだけで入ります。販売サイトのプリセットは**手数料率とサイト名を同時に**入れます。梱包材の**まとめ買い**（100 枚 800 円 → 1 枚あたり 8 円）は自動で割り算します。

#### タグ
色つきのタグで記録を分類。あとから「洋服だけ」のように絞り込めます。

#### CSV 書き出し
2 種類あります。「データ保存用」はメモやタグを含めた全項目、「確定申告用」は帳簿に要る列だけ。確定申告用では同じ日の売上を 1 行にまとめられます。書き出す前に中身をプレビューでき、共有シートからメール・ファイルアプリ・PC へ渡せます。

#### バックアップと復元
写真を含めたデータの書き出しと復元。機種変更のときはこのファイル 1 つで移せます。復元前に「読み込む中身」を確認できます。

## そのほか

- **日本語 / 英語** 対応（端末の設定に追従、アプリ内で固定も可能）
- **ライト / ダークテーマ** 自動切り替え
- 記録したデータは**端末内**にだけ保存され、外部へ送信していません。アカウント登録も不要です
- 広告を表示しているため、広告配信のための通信はあります（詳細は[プライバシーポリシー](https://hisakawaserai-svg.github.io/Profit-Calculator-App-RN/privacy.html)）

## 技術スタック

- **Expo**（React Native）+ TypeScript
- **expo-router** — ファイルベースルーティング（4 タブ + 各タブ内スタック）
- **expo-sqlite + drizzle-orm** — 永続化（マイグレーション管理つき）
- **zustand** — 状態管理
- **react-native-gifted-charts** / **react-native-svg** — グラフ・図版
- **react-native-reanimated** — アニメーション
- **vitest** — 計算・集計ロジックのテスト

## 開発

```bash
cd app-rn
npm install
npx expo start
```

ネイティブビルドは `npm run ios` / `npm run android`（`ios/` `android/` は prebuild 生成物のため git 管理外）。

```bash
npm test              # vitest
npm run lint          # eslint
npm run db:generate   # drizzle マイグレーション生成
```

## なぜソースを公開しているか

**透明性のためです。**

このアプリは、売上や仕入といったお金の情報を入力してもらうものです。手元の端末だけで完結し、どこにも送っていない ―― と説明することはできますが、閉じたアプリでは利用者にそれを確かめる手立てがありません。

だからソースを公開しています。何をしているアプリなのか、入力したデータをどう扱っているのかを、誰でも自分の目で検証できる状態にしておくためです。
